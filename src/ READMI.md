# Разработка серверного приложения

## Раздел: Серверное программирование

### Описание:

В рамках данной работы студенты должны будут спроектировать каркас для курсовой работы по дисциплине - асинхронный сервер для применения моделей машинного обучения и/или выполнения аналитических задач, нагруженных вычислений или для работы под высокой пользовательской нагрузкой.

## Ход работы
В следующих двух работах будет разрабатываться сервис матричных вычислений.

### Что получилось
1) Создан gRPC-сервер на порту 50051.
2) Реализован сервис MatrixService, который пока содержит один метод:
multiply — умножение двух матриц.

### Расшифровка магии

1) В файле matrix_service.proto описываем gRPC-сервис MatrixService с методом multiply, 
сообщения MatrixRequest, MatrixResponse и Row.
2) Реализация сервиса MatrixServiceImpl наследуется от MatrixServiceGrpc.MatrixServiceImplBase,
где мы переопределяем метод multiply.
Здесь мы принимаем MatrixRequest (две матрицы) и возвращаем MatrixResponse
(результат умножения).
3) Сервер поднимается на порту 50051, добавляя MatrixServiceImpl как сервис.
